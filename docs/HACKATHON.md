# OMO Proof: judging plan

PortalDot Hacker House, proposed Ecosystem DApps fit.

## Intended demonstration

Noncustodial community funding receipts tied to immutable campaign terms.

| Criterion                | Evidence to show                                                                         |
| ------------------------ | ---------------------------------------------------------------------------------------- |
| Specific user problem    | A concrete maintenance-team or community task, with the existing manual steps            |
| Technical implementation | The actual provider request, server-side validation and persisted result                 |
| Product experience       | One complete workflow, visible progress, useful error handling and a downloadable record |
| Distinctive idea         | Traceable reasoning or immutable terms, with a visible human approval boundary           |
| Credibility              | State the test environment, disclose synthetic data, and demonstrate a failure case      |

## Submission gates

- [ ] Confirm entrant eligibility and complete registration.
- [ ] Complete the live integration proof described in README.
- [ ] Verify deployed browser, API and storage behavior.
- [ ] Record the required video from the working system.
- [ ] Publish source, license, run instructions and private judge access.
- [ ] Complete any deck, progress report and live-demo obligations in the event portal.
- [ ] Submit before the confirmed deadline and retain the receipt.

No gate above has been marked complete merely because code or mocks exist. Do not fabricate usage, customers, transaction IDs, latency improvements or sponsor adoption.
