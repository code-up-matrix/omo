Open Agent needs Zetaris and Meterless, a source repository, a 1–4 minute workflow video and a slide deck. Its scoring weights are impact 30, technical 20, innovation 15, demo 15, UX 10 and sponsor use 10. Generated code is allowed and Cursor is optional. Declare dependencies, prior code, AI assistance and the actual NVIDIA contribution accurately.

PayPal requires a functional PayPal Developer Platform sandbox integration with AI, public licensed source with setup instructions, and an English video under three minutes. The viability/API gate comes first; implementation, design, impact, innovation and presentation then carry equal weight. A labeled synthetic walkthrough alone does not clear the functionality gate.

PortalDot is an EVM-capable ecosystem event. A local EVM test does not prove deployment on PortalDot. Registration, current network configuration, test tokens, progress reporting, official rubric details and demo obligations must be confirmed in the participant portal before claiming eligibility. Direct public page retrieval returned HTTP 405; indexed first-party snippets were accessible.

Other candidates excluded from immediate builds: Dakar Bitcoin is student-restricted; BCH BLAZE has a later November build window; QIE requires mainnet evidence and substantial entrant contribution. These constraints make them poorer fits for immediate autonomous provisioning. Do not reuse these repositories as undeclared pre-existing work in a future build-window event.
