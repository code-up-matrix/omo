# OMO Proof: recording script

Record the deployed application with configured test services. Keep credentials and private records out of the video. Target 2 minutes 40 seconds, comfortably inside PayPal's limit and Open Agent's range.

1. 0:00–0:20 — Introduce the user and their concrete problem. State that this is a test/sandbox environment.
2. 0:20–0:50 — Enter the task and show the proposed action or evidence. Explain what data is real and what is synthetic.
3. 0:50–1:40 — Complete the connected workflow. Show the actual provider result and the server verification.
4. 1:40–2:10 — Demonstrate a meaningful failure: missing evidence, an over-budget plan, or a mismatched receipt.
5. 2:10–2:30 — Download the result and show the matching audit record. Explain the sponsor contribution in the running application.
6. 2:30–2:40 — State the next milestone and link the repository.

Do not use test logs as a substitute for real end-to-end footage. Recording and upload remain entrant actions until the integration is live.
